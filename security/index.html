Vulnerability disclosure

Report a security issue.

A private route for reports affecting this website and its published source code.

Send a private report

Use GitHub’s private vulnerability reporting. You will need a GitHub account. Please avoid public issues or discussions for details that could expose people or enable abuse.

Include the affected URL or file, a clear description of the impact, the smallest safe reproduction and any relevant browser or version information. Redact passwords, access tokens and personal information.

Scope and coordination

This reporting route covers nexafusion.io, www.nexafusion.io and the lanano12/web repository. It does not grant permission to test client systems, GitHub infrastructure or other third-party services.

Keep testing limited to demonstrating the issue safely. Do not access other people’s information, disrupt availability, use social engineering or run high-volume scanning. If you encounter personal information, stop and describe the exposure without copying or publishing it.

The private report thread provides a place to clarify impact, discuss remediation and coordinate disclosure. There is no guaranteed response time or paid bounty programme.

Technical examples

The device architecture and update-verification examples use synthetic data. They are educational studies with explicit assumptions and limitations, not audited production implementations.
