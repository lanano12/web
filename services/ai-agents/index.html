How an engagement runs

  1. Diagnose (1–2 weeks). We read the code and the data, and agree the baseline and the number we expect to move.
  2. Prove (3–5 weeks). A thin, real slice in production, measured against that baseline.
  3. Scale and hand over. Widen the change with your engineers, then leave docs, runbooks and a team that owns it.
