Website privacy

Understand what this site uses.

A technical description of the site’s data flows and optional features.

Browsing

The site does not include analytics, advertising trackers or third-party fonts. It is hosted on GitHub Pages. Visiting it necessarily sends network information, such as your IP address and requested URL, to the hosting provider. See GitHub’s privacy statement for its processing practices.

Optional local preferences

Changing the colour theme on a detail page stores the selected theme in your browser’s local storage under nf-theme. It is not sent by the site’s code. Clearing this site’s browser storage removes the preference.

Checklists, search and demonstrations

The CRA checklist, navigation search and signature demonstration run in your browser. The site does not transmit or persist your checklist answers or search queries. Reloading the page clears them.

“Email this summary” opens a draft in your mail application. You can review it before sending. Sending email shares its contents and your address through your chosen email service; it is no longer local-only.

External links and private reports

Following an external link takes you to a separate service with its own practices. Security reports submitted through GitHub use GitHub’s private vulnerability-reporting feature.

For questions about this website’s data handling, contact hello@nexafusion.io. For a vulnerability, use the private reporting route.
